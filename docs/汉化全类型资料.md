# 游戏汉化全类型资料（以"改文件"为纲）

> 2026-09 调研定稿（根源路线版）。工具均已验真（⭐=GitHub 星数）。
> **"根源"= 改游戏/Mod 文件本体：解包 → 改文本/资源 → 回封 → 出补丁**；运行时钩子/OCR 只盖显示层，仅作快看备选。

## 0. 通用六步 + 两条铁律

1. **定位载体**：先找文本住哪（明文 → 资源包 → DLL/EXE → 贴图）
2. **解包 / 直改**：能直改就直改（UABEA / UndertaleModTool / OpenIV 类编辑器）；不能则解成 csv/json/txt 中间格式
3. **编码整流**：日游常 Shift-JIS → 统一 UTF-8/GBK；回封前逐文件校验（乱码第一来源）
4. **字体兜底**：换/缝字体防 □□，或改字体声明
5. **回封 / 覆盖**：重打包原格式，或按引擎规则用散文件覆盖
6. **分发验证**：出补丁包（xdelta3 / 7z / IPS）→ 重进游戏看屏验收 → 留原版备份

**铁律一 · 覆盖优先**：Ren'Py 丢 .rpy、KiriKiri 丢 patch.xp3、RM 改 www/、GTA 放 mods/、UE 进 Paks/~mods —— 汉化成品多是「免解包覆盖补丁」。
**铁律二 · 先验管道再转码**：ASCII 正常 + 高位字节烂 = 渲染管道假转换，重编码救不了（JC4 案例）。

### 文本住在哪（定位速查）

| 引擎 | 文本常见位置 |
|:--|:--|
| Unity | `<Game>_Data/resources.assets`、`*.bundle`、StreamingAssets |
| UE4/5 | `Content/Paks/*.pak` 内 `.locres` / `.uasset` |
| GameMaker | `data.win` |
| Ren'Py | `game/**/*.rpy(.rpyc)`、`game/tl/<lang>/` |
| RM MV/MZ | `www/data/*.json`、`www/js/plugins` |
| RM 旧代 | `Data/*.rxdata` / `*.rvdata2` |
| KiriKiri | `*.xp3`（data.xp3 / patch.xp3） |
| Wolf RPG | `Data/` 等数据文件（wolftrans 处理） |
| Godot | `*.pck` / 内嵌 exe |
| Bethesda | `*.esp/esm` + `.strings/.dlstrings/.ilstrings`（+`.bsa`） |
| GTA RAGE | `*.rpf`（gxt2、脚本） |
| CDPR | `content/packed/*.archive`（w3strings/json） |
| 明文类 | 直接可见的 json/yml/xml/lua |

## 1. 各引擎根源管线（文件 → 工具 → 回封）

### Unity
- **直改**：UABEA ⭐2438 打开资源包 → 选 TextAsset → Plugins→Edit → Save（原文件直接生效）
- **批量**：UnityPy（python）；整项目导出：AssetRipper ⭐8420；查结构：AssetStudio ⭐15601
- **进阶**：Il2CppDumper ⭐9434（il2cpp 符号）、dnSpyEx ⭐11134（mono 游戏 C# 层）
- **字体**：TMP 字体资产替换（SDF 重烘，见第 4 节）

### Unreal（UE4/UE5）
- **解包**：repak ⭐573 / UEExtractor ⭐64 / FModel ⭐3184（查看）
- **改 locres**：UnrealLocres ⭐157（csv 进出）、UE4LocalizationsTool ⭐171、LocresStudio、UnrealLocresEditor ⭐61
- **回封**：repak/UnrealPak → `xxx_P.pak` → `Paks/~mods`
- **实例**：Nexus《Pak modification process - text modification》（黑神话 mods/337）；1a4.top《记一次UE4汉化》

### GameMaker
- `data.win` 直改：UndertaleModTool ⭐2060 → 改字符串/字体 → Save

### Ren'Py
- **原生框架**：`renpy <proj> translate <lang>` → `game/tl/<lang>/*.rpy` 填译文 → 随游戏发布（官方文档 renpy.org/doc/html/translations.html）
- **散文件覆盖**：.rpyc → unrpyc ⭐1258 → 改 .rpy → 放回自动重编译
- **字体**：放 ttf + 改 gui.rpy；**自动化**：RenpyBox（Dclef/renpybox ⭐57）
- **教程**：docs.dclef.com + Dclef/renpy-tl ⭐92

### RPG Maker
- **MV/MZ**：`www/data/*.json` 直改（UTF-8）；SExtractor ⭐507 提取→译→回填
- **旧代**：`.rxdata/.rvdata2` → RPG Maker Trans（rpgmakertrans.bitbucket.org；v4.5 archive.org 存档）；Translator++ 可导入其补丁
- **内嵌补丁**：MTool 译文 JSON 转"内嵌式补丁"（拒绝挂载式；2dfan.com/posts/29146）
- **教程**：Dclef/RPGmaker-Translation ⭐52

### KiriKiri / KAG
- **解包**：GARbro ⭐3305 / krkrxp3 → **改** `.ks`（常 Shift-JIS，先转码！保护 KAG 标签/TJS）→ **回封** `patch.xp3`（按加载优先级命名）
- **字体**：优先改 KAG/TJS 字体声明
- **样例**：Galgame-AgentLab 的 kirikiri-xp3-patch.md；视频课：ZQF-ReVN/VN_Localization_Tutorials ⭐123

### Wolf RPG
- wolftrans（gem 安装）：extract 明文 → 翻译 → apply 生成译文版游戏文件；wolfTL / wolftrans_py 同族

### LiveMaker
- 教程：CyanidEEEEE/Livemaker-chinese-tl ⭐55

### Godot
- gdsdecomp ⭐4233：整项目恢复（GDScript 反编译）→ 改 → **内置 PCK 打包**；GodotPckTool ⭐577 备选

### 贝塞斯达
- xTranslator：直接编辑 ESP/ESM + strings → 保存即汉化插件；BSA 解包取串；MO2 分发

### GTA（RAGE）
- OpenIV：`*.rpf` 提取→改→导入回；`mods/` 机制保原档；CodeWalker ⭐755 进阶

### CDPR
- WolvenKit ⭐1198：archive → w3strings/json → 打包成 mod

### 明文类 / 主机 ROM
- Paradox yml、MC lang json、Stardew i18n、SMF 等：直改+打包
- ROM：CrystalTile2 / tiledggd + IPS/UPS；教程 B站 cv26611275
