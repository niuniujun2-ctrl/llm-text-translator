# 管线指南（本地 LLM 批量翻译：细节、质量门与坑）

> 出自 HITMAN SMF 汉化实战（约 2.8 万条文本）。适用于任何「JSON 文本 → 批量翻译 → 写回」场景。

## 0. 总览

```
extract ─ corpus.jsonl ─ quality_check ─ retranslate(build→translate→writeback) ─ build_table
                              ▲                                                     │
                              └────────────── 复检（再跑一遍 extract+质检）──────────┘
```

## 1. 模型准备（llama.cpp）

推荐腾讯混元 HY-MT1.5-7B（翻译专模，Q4_K_M 约 4.6GB）：

```bash
llama-server.exe -m models/HY-MT1.5-7B-Q4_K_M.gguf -ngl 999 -c 16384 -t 16 -fa on \
  -b 4096 -ub 512 -ctk q4_0 -ctv q4_0 --mlock --host 127.0.0.1 --port 8080 \
  --temp 0.3 --repeat-penalty 1.05 --top-k 20 --top-p 0.6 --cache-reuse 256 --context-shift
```

- 端点：`http://127.0.0.1:8080/v1/chat/completions`（可用环境变量 `LLM_ENDPOINT` 覆盖）；
- 官方推荐参数：temperature 0.3 / top-k 20 / top-p 0.6（翻译别贪高温）；
- 并发：服务器 `n_parallel`（默认 4）↔ `retranslate.py` 的 `CONCURRENCY`。

## 2. 批翻译协议（踩坑后的选择）

- **行号协议** `1. text` / `1. 译文`：比要求 JSON 数组回显稳定得多；
  行号一律用「批内相对序号」——模型会自行重编号，全局序号必然对歪。
- **BATCH≈25 条**：更大常触发 max_tokens 截断 → 漏行。
- **漏行 = 截断信号** → 递归对半拆分重试，绝不带着缺行继续。
- 产出逐批 append 到 `done.jsonl`；重启先读已完成 id 跳过（last-wins 去重）。
- 后台跑一律 `python -u`（无缓冲），否则错误会被缓冲吞掉几小时。

## 3. 质量门（写回之前）

- **简繁混杂**：cn 用 `t2s`、tc 用 `s2t` 探测；维护豁免表
  （雇/僱、念/唸、秘/祕、里/裡、台/臺 等两岸通用字不算错）。
- **占位符/标签**：`{0}` `%s` `<li></li>` `<br>` 的数量与顺序核对（`qa/qa_placeholders.py`）。
- **空译/漏译**：原文非空而译文空；译文明显过短（< 45% 原文）抽检。
- **乱码**：`U+FFFD` / 锟斤拷 / 烫烫烫。
- **零和谐**：脏话/敏感语被软化或删除（`qa/qa_harmony.py` + 自定义词表）。
- **复检**：**写回之后再跑一遍 extract + quality_check** —— 语料变了，报告也要重生成。

## 4. 写回纪律

- 先备份（整目录快照级）；
- 保持每个文件原有格式：缩进（逐文件探测 tab vs 空格）、BOM、CRLF/LF；
- cn/tc 双写，`tc = OpenCC s2t(cn)`；
- 写回后再 extract，对比新旧语料，确认只有目标字段变化。

## 5. 术语与风格

- **术语表先行**（人名/地名/物品/技能），运行中持续补充；续作继承前作译名。
- 官方/社区既有译名优先。
- 尊重排比与语力；不用网络流行语（时代错位会翻车）。
- 控制代码（占位符/标签/转义）原样保留——在提示里写清楚，别指望模型自觉。

## 6. 坑列表（浓缩）

1. **术语表全文替换会误伤**——短 key（`and`、`F/A`）会打坏标识符/武器型号；
   正确姿势：先检测残留 token，只对残留整词替换，维护 KEEP_EN 豁免表。
2. **模型输出噪声必清**：`> `、`- ` 前缀、行号残留、`X | X` 分隔符。
3. `wc -l` 数 JSONL 进度不可靠（CRLF/半行写入）——解析 JSON 计数或取 max id。
4. 杀 bash 包装进程**不会**杀 python 子进程（孤儿进程并发写同一文件）——
   按命令行匹配全杀再重启；venv 的 python.exe 可能是 shim（成对父子进程是正常的）。
5. 长文本先小批实测吞吐（tokens/s × 并发）再估总时长，别拍脑袋。
6. 字幕/对白类条目：时间轴前缀与说话人记号（`//[SPEAKER]\\`）要与正文分离处理，
   别让模型碰。
7. 非目标语言的专名（品牌/型号/代号）保留原文是常态；要「全部翻译」须显式列豁免清单。
8. 写回目标是游戏目录里的文件时：**先确认游戏没在运行**（文件被锁会写失败或白写）。
